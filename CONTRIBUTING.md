# Contributing to My Wisely

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.

## How to Contribute
1. Review open issues and discussions.
2. Suggest improvements or new features.
3. Submit well‑documented code with tests.
4. Ensure commits are clear and descriptive.

## Reporting Issues
- Use the issue tracker to report bugs.
- Provide steps to reproduce and screenshots if possible.
- Label issues appropriately.

## Suggesting Features
- Open a feature request issue.
- Explain the problem your idea solves.
- Provide examples or mockups if available.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or offensive language.
- Collaborate constructively.

## Review Process
- Pull requests are reviewed by maintainers.
- Feedback will be provided for improvements.
- Approved PRs will be merged into the main branch.
